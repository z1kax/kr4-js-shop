# KeyStore - интерактивный магазин клавиатур

Контрольная работа №4.
Тема: «JavaScript: интерактивность, DOM, события, формы и валидация».

## Описание проекта

KeyStore - учебный интернет-магазин клавиатур. В КР №4 к готовому адаптивному сайту добавлена интерактивность на чистом JavaScript: каталог товаров генерируется из массива, работают поиск, фильтр и сортировка, корзина с сохранением в localStorage, тёмная тема и валидация формы заявки с выводом ошибок на страницу. Фреймворки и библиотеки не используются.

## Основа проекта

Проект `kr4-js-shop` создан на основе адаптивной версии магазина из КР №3 (репозиторий `kr3-responsive-shop`). Наследие КР №3: раскладка Mobile First, медиазапросы, responsive images, базовая доступность.

## Назначение JavaScript-файлов

- `data.js` - массив товаров, единый источник данных каталога.
- `catalog.js` - каталог: ссылки на элементы, состояние `catalogState`, функции обработки данных, генерация карточек через `createElement`, рендер, обработчики поиска, фильтра и сортировки, делегирование событий кнопок карточки.
- `cart.js` - корзина: добавление, удаление, очистка, количество и сумма через `reduce`, сохранение и восстановление из `localStorage`, вывод страницы корзины.
- `validation.js` - валидация формы заявки на `order.html`: проверки полей, ошибки рядом с полями, имитация отправки.
- `theme.js` - тёмная тема: переключение класса на `body`, сохранение выбора в `localStorage`, состояние кнопки переключения.
- `main.js` - общая инициализация: открытие и закрытие модального окна, подстановка выбранного товара в скрытое поле формы.

## Массив товаров

В `data.js` 8 товаров единой структуры: `id`, `title`, `category`, `price`, `discountPercent`, `rating`, `isAvailable`, `badge`, `image`, `description`.

- `id` уникальны;
- цены записаны числами, а не строками;
- категории `mechanical`, `membrane`, `wireless` совпадают со значениями `option value` фильтра каталога;
- для Corsair K55 RGB PRO и Razer Pro Type Ultra стоят SVG-заглушки изображений до появления фотографий.

## Поиск

Событие `input` на поле `#catalog-search` записывает значение в `catalogState.query` и вызывает `updateCatalog()`. Внутри `searchProducts` запрос нормализуется: `trim()` убирает пробелы по краям, `toLowerCase()` убирает зависимость от регистра, `includes()` проверяет вхождение подстроки в название товара. Пустой запрос возвращает все товары.

## Фильтрация

Событие `change` на списке `#category-filter` обновляет `catalogState.category`. Значение `all` возвращает все товары, иначе фильтр оставляет товары со строгим равенством `product.category === category`.

## Сортировка

Событие `change` на списке `#sort-select` обновляет `catalogState.sort`. Значения: `default`, `price-asc`, `price-desc`, `title-asc`. Сортировка выполняется на копии массива через `[...products]`, поэтому исходный порядок данных не нарушается. Названия сравниваются через `localeCompare`.

## Форма и валидация

Форма на `order.html` имеет атрибут `novalidate`: браузерные подсказки отключены, ошибки выводит собственный код. При отправке `preventDefault()` отменяет перезагрузку страницы. Проверяются: имя не короче 2 символов, e-mail по шаблону, телефон по 11 значимым цифрам, начинающимся с 7 или 8, отмеченный чекбокс согласия. Текст ошибки пишется рядом с полем через `textContent`, поле получает `aria-invalid` и `aria-describedby`. Ошибки очищаются при `input` и `change`. При успехе кнопка переходит в состояние «Отправка...», после задержки 800 мс (имитация отправки) выводится сообщение об успешной подготовке заявки и форма сбрасывается. `alert()` не используется.

## Безопасный вывод данных

Все текстовые данные выводятся через `textContent` и создание элементов через `document.createElement()`. `innerHTML` не используется для пользовательских данных, данных формы и данных из `localStorage`. Причина: `innerHTML` интерпретирует строку как HTML-разметку, поэтому вредоносная строка может выполниться на странице (XSS). Контрольная строка `<img src=x onerror=alert(1)>` выводится как текст и не выполняется.

## Самостоятельные доработки

- Корзина с добавлением, удалением и очисткой товаров.
- Расчёт количества позиций и суммы корзины через `reduce`.
- Сохранение корзины в `localStorage` (ключ `keystore-cart`): чтение через `JSON.parse` внутри `try/catch` с проверкой типов каждого элемента.
- Тёмная тема (ключ `keystore-theme`): класс `theme-dark` на `body`, палитра через переопределение CSS-переменных, выбор сохраняется после перезагрузки.
- Улучшенная форма: проверка согласия, имитация отправки с задержкой, состояния кнопки, сброс формы после успеха.
- Улучшения UX: счётчик найденных товаров, счётчик корзины, бейджи «Скидка», «Хит», «Новинка», статус наличия с отключёнными кнопками, пустое состояние каталога, округление цены со скидкой при выводе.
- Структура кода по файлам: данные, каталог, корзина, валидация, тема и общая инициализация разделены, дублирования функций между файлами нет.
