# Контрольная работа №4

Тема: «JavaScript: интерактивность, DOM, события, формы и валидация».

Проект: KeyStore - интернет-магазин клавиатур на чистом JavaScript.

## Основа проекта

Проект `kr4-js-shop` создан на основе адаптивной версии HTML/CSS-интернет-магазина из контрольной работы №3 (`kr3-responsive-shop`).

Наследие КР №3:
- подход Mobile First, медиазапросы, проверенные ширины 360, 430, 768, 1024, 1440 px;
- адаптивные сетка карточек, форма заявки и таблица характеристик;
- responsive images через `srcset` и `sizes`;
- базовая доступность: skip-link, видимый фокус, `label`, `alt`, контраст;
- Lighthouse Accessibility: 100 баллов, отчёты в папке `lighthouse/`;
- опубликованная версия КР №3: https://z1kax.github.io/kr3-responsive-shop/

## Принцип безопасного вывода данных

Для пользовательских данных и данных, которые в будущем могут прийти из формы, `localStorage` или API, используется `textContent`, а не `innerHTML`.

Причина: `innerHTML` воспринимает строку как HTML-разметку, поэтому вредоносная строка может выполниться на странице. `textContent` выводит строку как обычный текст и не интерпретирует разметку.
